# Handoff Contracts

Every agent handoff should include:

## Required Input

- current state
- artifact being reviewed or produced
- role-specific brief
- explicit unresolved questions
- what must not change

## Required Output

- verdict
- main findings
- required changes
- optional improvements
- ready/not-ready decision
- next recommended owner

## Handoff Discipline

- Do not pass vague approvals.
- Do not pass drafts without role-specific findings.
- Do not erase prior decisions unless escalation is explicit.
- Do not rewrite outside role boundaries unless the workflow authorizes it.
